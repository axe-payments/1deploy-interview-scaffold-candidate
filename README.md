# 1deploy-interview-scaffold-candidate

Candidate-facing starter application for a two-hour, AI-permitted fleet heartbeat alerting interview.

This repository is at the planning stage. No application has been implemented.
The detailed handoff is proposed at `docs/plans/implementation-plan.md` on the
`docs/implementation-plan` branch.

Local settings use **`env.local`** (untracked); **`env.example`** is the tracked
template. Credentials in the example are blank. Set only local or dedicated
interview integration values in your own `env.local`.

Do not add candidate transcripts, assessments, or hiring records to this repository.
